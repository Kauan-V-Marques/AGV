PACOTE DE EXECUTAVEIS AGV
=========================

1) PC DO AGV (Linux)
--------------------
Pasta: EXECUTAVEIS/agv_pc
Arquivos:
- iniciar_sistema
- launch_production
- RODAR_AGV.sh

Como rodar:
cd EXECUTAVEIS/agv_pc
./RODAR_AGV.sh

Observacao:
- Este modo precisa do Kinect conectado no PC AGV.
- Se o Kinect nao for detectado, o servidor encerra.

2) PC REMOTO DE CONTROLE (Linux)
--------------------------------
Pasta: EXECUTAVEIS/controle_remoto_pc
Arquivos:
- iniciar_controle
- RODAR_CONTROLE.sh

Como rodar (troque o IP):
cd EXECUTAVEIS/controle_remoto_pc
AGV_IP=192.168.0.50 AGV_PORT=5000 ./RODAR_CONTROLE.sh

O que faz:
- Abre o painel do AGV no navegador.
- Permite controle por teclado no terminal (WASD + X + M/U).

3) TESTE LOCAL (1 PC)
---------------------
Pasta: EXECUTAVEIS/teste_local_pc
Arquivos:
- ver_site_teste
- RODAR_TESTE_LOCAL.sh

Como rodar:
cd EXECUTAVEIS/teste_local_pc
./RODAR_TESTE_LOCAL.sh

O que faz:
- Sobe o servidor local.
- Abre o site automaticamente.
- Bom para validar camera/painel no mesmo computador.

4) FLUXO RECOMENDADO (2 PCs)
----------------------------
Passo A: No PC AGV, rode RODAR_AGV.sh
Passo B: Descubra IP do AGV com: hostname -I
Passo C: No PC remoto, rode RODAR_CONTROLE.sh com AGV_IP

5) POSSIVEL ERRO
----------------
Erro: "Nenhum Kinect encontrado"
- Verifique cabo USB do Kinect
- Verifique alimentacao do Kinect
- Reconecte e rode novamente
